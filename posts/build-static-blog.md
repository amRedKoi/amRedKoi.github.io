静态博客由预先构建好的 HTML 文件组成，访问时浏览器直接读取文件，无需后端渲染。

## 静态博客的优势

1. **极速加载**：没有服务器运算，页面秒开。
2. **安全稳定**：无数据库、无接口，攻击面小。
3. **免费托管**：GitHub Pages、Vercel、Netlify 等都支持。

## 核心实现

我们把文章数据存在一个 JS 文件中：

```js
// assets/js/posts.js
window.posts = [
  { id: "hello", title: "你好", category: "随笔" }
];
```

首页通过循环渲染卡片，点击后根据 `id` 找到对应文章并填充到详情页。

> 优雅的页面，不需要复杂的框架。
