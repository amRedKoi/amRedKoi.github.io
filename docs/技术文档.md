# amRedKoi 个人小站 · 技术文档

本文档依据当前仓库源码整理，面向**二次开发与维护**。内容覆盖：架构总览、目录结构、页面路由、数据层、核心模块（`main.js`）、Markdown 渲染管线、交互式图表（Bode / PID）、主题系统、构建与部署。

## 1. 项目概述

纯前端静态站点（零后端、零构建框架）：

- **技术栈**：HTML5 + CSS3（自定义属性变量）+ 原生 JavaScript（ES2020+）
- **部署**：GitHub Pages（`actions/deploy-pages` 推送 `main` 自动发布）
- **内容形态**：文章为 Markdown（`posts/*.md`），其余内容全部由 JS 数据文件驱动（`posts.js` / `projects.js` / `site-data.js`）
- **第三方依赖**：仅浏览器端本地化（`assets/vendor/`）的 `markdown-it` + `KaTeX`；公式/语法高亮均有**零依赖兜底实现**，离线打开也能渲染

## 3. 页面路由与初始化分发

站点为多页 HTML，通过 `<body data-page="...">` 标记当前页面，`main.js` 在 `DOMContentLoaded` 时按页面分发初始化：

| data-page | 页面 | 分发逻辑（main.js 末尾） |
|---|---|---|
| `home` | index.html | `initTypewriter` `renderProfile` `renderTimeline` `renderHomeResources` `renderHomePosts` `computeSiteStats` `initReveal` |
| `blog` | blog.html | `initBlog`（列表/筛选/分页）+ `renderMoments`（动态） |
| `resources` | resources.html | `renderProjects` `renderLinkGroups` `initNotice` `initResourceNav` |
| `post` | post.html | `initBackLink` + `renderPost`（含大纲 `buildPostToc`） |
| `docs` | docs.html | `renderDocs`：渲染 `docs/技术文档.md`，含 A4 布局与大纲 |
| `about` | about.html | 无 JS 渲染，纯静态卡片 |

全局初始化（所有页面）：`initTheme` → `initAccentPicker` → `initSidebarDrawer` → `initDailyQuote` → `initBackToTop` → `initReadingProgress` → `initLightbox` → `bumpVisits`。

### 3.1 通用工具

- `getParam(name)`：读取 `URLSearchParams`。
- `formatDate(iso)`：`YYYY-MM-DD` 友好化。
- `calcAge(birthday)`：由生日计算年龄（`renderProfile` 用）。
- `formatDuration(totalDays)`：将累计天数格式化为 "X 年 Y 天"（`computeSiteStats` 用）。

## 4. 数据层

三个数据文件向全局暴露对象，供 `main.js` 消费。**新增内容只需改数据文件，无需动 HTML 结构。**

### 4.1 `window.posts`（posts.js）

文章元数据数组，字段：

```js
{
  id: "minimum-phase-elements",   // 唯一 ID，post.html?id= 定位
  title: "文章标题",
  category: "技术",                // 分类（博客页筛选）
  date: "2026-08-10",              // YYYY-MM-DD，列表按此降序
  excerpt: "首页/列表卡片摘要",
  file: "posts/xxx.md",            // 正文 Markdown 文件（与 content 二选一）
  // content: "<p>内联 HTML</p>",  // 兼容直接内联正文
  // tags: ["控制", "信号"],        // 可选，参与标签云与筛选
}
```

消费方：`renderFilters`（分类）、`renderTags`（标签云）、`renderPosts`（列表+搜索+分页）、`renderHomePosts`（首页最新）、`renderPost`（详情）、`computeSiteStats`（统计）、`generate-feed.mjs`（RSS）。

### 4.2 `window.projects`（projects.js）

```js
{
  name: "项目名",
  icon: "icon-xxx",          // assets/icons.svg 中符号
  desc: "一句话介绍",
  link: "https://…",         // 空串表示无链接
  tags: ["HTML", "CSS"],     // 小标签
}
```

消费方：`renderProjects`（资源页 + 首页项目区共用）。

### 4.3 `window.siteData`（site-data.js）

| 字段 | 类型 | 用途 |
|---|---|---|
| `profile` | object | 首页「关于我」：姓名、简介、`info[]`（生日/坐标/喜好…）、`tags[]`、`motto`、`socials[]` |
| `timeline` | array | 首页「我的经历」逐年条目（`year` + `icon` + `title` + `desc`） |
| `resources` | array | 首页「资源与模型」预览卡片（`id`/`name`/`desc`/`icon`/`tags`/`target`） |
| `models` | array | 资源页 Bode 模型目录项（`id`/`name`/`icon`/`desc`/`target`） |
| `moments` | array | 博客页「动态」朋友圈流（`author`/`avatar`/`time`/`text`/`images[]`/`likes`/`comments[]`）；`images[]` 为 QQ 空间式九宫格：1 张放大原比例、2 张两列并排、3–9 张 3 列网格、>9 张仅显示前 9 张并叠加 `+N` 角标 |
| `notice` | string | 博客页 / 资源页顶部滚动公告文字 |
| `linkGroups` | array | 资源页「网址收藏」分组（`id`/`icon`/`title`/`desc`/`items[{name,url}]`） |
| `site` | object | 首页「关于本站」统计（建站日、`desc`） |

## 5. 核心模块 main.js

按功能分区（约 1570 行），自上而下：

### 5.1 主题系统

- `THEME_KEY` / `applyTheme` / `initTheme`：深浅主题三元循环（浅 → 深 → 系统），优先 `localStorage`，其次 `prefers-color-scheme`，切换时同步按钮图标与 `aria-label`。
- 主题色：
  - `ACCENT_KEY` / `ACCENT_PRESETS`：7 组预设主题色（每组 `name` + `value`）。
  - `applyAccent` / `clearAccent` / `applySavedAccent`：通过 `hexToRgb` + `shadeHex` 计算明暗两档，写入 CSS 变量 `--accent` / `--accent-soft`（见 §7）。
  - `initAccentPicker`：吸顶栏色板弹层，含预设色块、自定义 `<input type="color">`、重置按钮，点击外部 / `Esc` 关闭。

### 5.2 首页渲染

- `initTypewriter` + `TYPEWRITER_PHRASES`：Hero 打字机循环（打字/停顿/删除）。
- `renderProfile` / `renderTimeline` / `renderHomeResources` / `renderHomePosts`：分别渲染 §4 数据。
- `computeSiteStats`：累计建站天数 + 文章数 + 总字数 + 本地访问量（`bumpVisits` 写入 `localStorage`）。
- `initReveal` / `animateCount`：`IntersectionObserver` 实现滚动入场动画与数字滚动。

### 5.3 博客列表

- 全局 `state = { category, tag, keyword, page }`。
- `renderFilters` / `renderTags` / `renderPosts` / `renderPagination` / `buildPageList`：分类胶囊、标签云（带计数）、卡片列表（过滤 + 搜索 + 每页 `PAGE_SIZE` 条）、页码条（当前页前后缩略）。
- `initBlog`：绑定搜索输入防抖、分页点击、`hashchange`（支持 `#tag` 直达标签）。
- `switchView`：**文章 / 动态 Tab**（`data-view` 属性，同步 `aria-selected`；`blog.html#moments` 可直达动态视图）。
- `renderMoments`：动态朋友圈卡片，全程 `createElement` 安全构建（不拼 HTML）。图片渲染为 QQ 空间式九宫格（见 §4.3）：容器 `.moment-images` 带 `data-count`（1–9）控制列数，`data-all-images` 存完整图片列表 JSON；>9 张时只渲染前 9 个 `.moment-img`（`<button>`），最后一张内叠加 `.moment-img-more` 角标显示 `+N`。点击任意图片进入相册灯箱（见 §5.7）。

### 5.4 公告滚动条

- `initNotice`：读取 `siteData.notice`，将文本反复拼接为**长度不小于视口宽度**的单元，再复制一份组成无缝轨道（`track.innerHTML = unit + unit`），配合 CSS 动画 `notice-scroll 8s linear infinite`（`from { translateX(0) } to { translateX(-50%) }`）实现无缝左移。

### 5.5 文章详情页

- `renderPost`：`getParam("id")` 在 `window.posts` 查找 → 渲染标题/日期/分类/标签 → 按 `content` 或 `file` 拉取正文 → `renderMarkdown()` → `enhanceCodeBlocks` → `buildPostToc`。
- `buildPostToc`：扫描正文 `h2/h3/h4`，自动生成唯一 `id` 与右侧大纲（三级缩进）；点击平滑滚动 + `history.replaceState` 更新锚点；`IntersectionObserver` 实现 scrollspy 高亮当前小节。无标题时大纲栏自动隐藏。
- `initBackLink`：`document.referrer` 同源判断——站内进入显示「返回上一页」（`history.back()`），直开/外站显示「返回首页」。
- `enhanceCodeBlocks` + `copyCode` + `CODE_LANG_LABELS`：为代码块加语言徽标、文件名（代码块首行如 `<!-- file -->` 注释）、复制按钮。

### 5.6 资源页

- `renderLinkGroups`：网址分组卡片，`faviconFor` 优先取 Google favicon 服务并缓存，失败降级为首字母圆标。
- `initResourceNav`：右侧分类锚点导航（`IntersectionObserver` scrollspy + 平滑滚动 + 激活态切换）。

### 5.7 通用 UI

- `initSidebarDrawer`：窄屏侧边抽屉（Esc / 遮罩点击 / 视口放大自动关闭）。
- `initBackToTop`：回到顶部按钮（滚动超过阈值显示）。
- `initReadingProgress`：顶部阅读进度条。
- `initLightbox` / `openLightbox` / `showLightboxImage` / `closeLightbox`：**相册式灯箱**——文章正文图与动态九宫格共用；`openLightbox(items, index)` 接收图片数组，支持左右箭头 / `←` `→` 键循环翻看（`(index + n) % n`）、顶部 `x / n` 计数、Esc / 点遮罩关闭。动态图优先读 `data-all-images` 完整列表（含 >9 张被折叠的图）。
- `initDailyQuote` + `DAILY_QUOTES`：每日一句（按日期取模轮换）。

### 5.8 技术文档页

- `docs.html`：与 `post.html` 同结构的独立页面，`<body data-page="docs">`。
- `renderDocs`：`fetch("docs/技术文档.md")` 拉取 Markdown → `renderMarkdown` → `enhanceCodeBlocks` → `buildPostToc`；失败时显示 `fetch` 受限提示。
- 与文章页共用 A4 正文 + 右侧大纲，首页「关于本站」新增入口卡片。

## 6. Markdown 渲染管线（markdown.js）

两套引擎，自动降级：

1. **主引擎**：`markdown-it`（`assets/vendor/markdown-it/`）+ `KaTeX`（`assets/vendor/katex/`），在 `post.html` 显式引用 vendor 脚本。
2. **兜底引擎**：内置零依赖解析器（`renderMarkdown`），当 vendor 未加载（如 `file://` 直开受限）时自动启用，**公式语法保持一致**。

### 6.1 公式

- 行内 `$...$`，块级 `$$...$$`（可跨行）。
- 有 KaTeX：`loadEngine` 注册 `math_block` / `math_inline` 规则走 KaTeX。
- 无 KaTeX：内置 `MATH` 表（希腊字母 / 常见符号 / 上下标 / 分式 `\frac` / 根式 / 求和极限 / 运算符 + 上下限 / `\begin{aligned}` 等常用环境）做 HTML 排版。
- 首尾不能为空格，`\$` 输出字面美元符；KaTeX 不支持的命令原样显示不报错。

### 6.2 代码高亮（零依赖）

- `highlightCode`：按语言分词染色，支持 20+ 语言：`js/ts/jsx/tsx`、`html/xml/svg`、`css/scss/less`、`json`、`python`、`bash/sh/shell/zsh`、`sql`、`java`、`c/cpp/c++/h/hpp`、`csharp/cs`、`go`、`rust`、`yaml/yml`、`markdown`、`plain/text/txt`。
- 每语言一套 `LANG_SPECS`（关键词、内建、注释、字符串、类型、多行注释等 token 规则）。
- 代码块渲染：`renderBlocks` 识别围栏（含语言名），`extractCodeBlocks` 先行抽取占位避免 Markdown 转义干扰，最后回填高亮 HTML。

### 6.3 内嵌 Bode 图

- 文章正文支持 `bode` 围栏代码块，内容为 JSON 规范；渲染器将其转为 `<div class="bode-plot" data-spec="...">`，由 `bode.js` 扫描绘制（见 §7.1）。
- 示例（在真实文章中围栏语言写 `bode`，此处写 `json` 仅作展示，避免被识别执行）：

```json
{
  "title": "示例系统",
  "fmin": 0.01,
  "fmax": 1000,
  "series": [
    { "label": "G(s)", "elements": [
      { "type": "gain", "K": 1 },
      { "type": "inertia", "K": 1, "T": 1 }
    ]}
  ]
}
```

- 规范字段：`title`（标题）、`fmin` / `fmax`（频率范围 Hz）、`series[]`（每项含 `label` 图例名 + `elements[]` 环节串联相乘）；环节类型与参数见 §7.1。

## 7. 交互式图表模块

### 7.1 bode.js —— 文章内 Bode 图（零依赖 Canvas）

- 支持环节（`elements` 串联相乘）：`gain`、`integrator`、`differentiator`、`inertia`（一阶惯性）、`lead`（一阶超前/滞后，`T` 与 `n` 正负控制）、`osc`/`osc2`（二阶振荡，`wn` + `xi`）、`delay`（纯延迟）、`poly`（多项式 `num`/`den`）。
- 绘制幅频 `L(ω)/dB` 与相频 `φ(ω)/°` 双面板，自动纵轴刻度（`niceBounds`）。
- 主题响应：读取 `getComputedStyle` 的 CSS 变量颜色，深色模式自动适配；监听 `data-theme` 变化重绘。

### 7.2 bode-editor.js —— 资源页交互式 Bode 编辑器

- **表达式解析**：`tokenize` → `Parser`（递归下降，支持括号/幂/函数）→ AST → `evalNode`（含复数 `C` 类四则/共轭/exp/ln/pow/sqrt 运算）。
- **参数提取**：`parseExpr` 自动收集变量（如 `s`）与参数（如 `K`、`T`、`zeta`、`wn`），`paramMeta` 定义默认值 / 范围 / 步长，`init` 据此生成参数滑杆。
- **绘制**：`drawBodeEditor` 双面板 Canvas，随滑杆实时重绘；`apply` 切换预设模型（`siteData.models` 锚点直达）。
- 主题响应：`MutationObserver` 监听 `data-theme` 刷新配色。

### 7.3 pid-sim.js —— PID 控制系统仿真

- 被控对象：二阶振荡系统 `OBJECT = { wn, zeta }`（`H(s)` 闭环传递函数）。
- PID：`PARAMS = { kp, ki, kd }`，积分环节带 `INTEGRAL_LIMIT` 抗饱和；差分法（`DT` 步长）离散递推 `step`。
- 输入参考：阶跃 / 斜坡（`reference.ramp`）；可加外部扰动 `externalDisturbance`。
- 输出：`y / u / ref / err` 四条轨迹，Canvas 实时绘制 + 读取 CSS 变量适配主题；滑杆拖动实时生效（`bindSlider`），`requestAnimationFrame` 驱动仿真循环。

## 8. 主题系统（style.css）

所有颜色集中在 `:root`（浅色）与 `[data-theme="dark"]`（深色）的 CSS 变量，JS 只改变量值，样式零改动。

核心变量（示意）：

| 变量 | 作用 |
|---|---|
| `--text` / `--text-muted` / `--text-strong` | 正文 / 次级 / 强调文字（卡片摘要用 strong） |
| `--card` / `--card-soft` / `--border` | 卡片、柔和底色、边框 |
| `--accent` / `--accent-soft` | 主题色 / 主题色柔和底（JS 动态注入） |
| `--shadow` / `--shadow-sm` | 卡片阴影 |
| `--radius` / `--topbar-h` / `--blog-max-width` | 圆角、顶栏高度、宽页最大宽度 |

- 主题色通过 `applyAccent` 计算：浅色模式用主题色作为 `--accent`、其 12% 透明度混合作为 `--accent-soft`；深色模式取主题色提亮档。
- 页面分区使用 `body[data-page="blog|resources|post"]` 选择器加宽内容区（`--blog-max-width`）。

## 9. 文章页 A4 布局与大纲

- 容器 `post.html` 使用 `.post-layout` 两栏 Grid：`794px`（≈210mm，A4 宽）+ `232px` 大纲。
- 正文 `.article-body` 最小高度 `1123px`（≈297mm，A4 高），短文章呈竖版纸形态，长文章自然增高；`padding: 56px 60px` 留白接近纸张边距。
- 右侧 `.post-toc` 为 `position: sticky` 侧栏，随滚动跟随；窄屏（`≤900px`）隐藏大纲恢复通栏阅读。
- 标题 `scroll-margin-top` 保证锚点跳转不顶到吸顶栏。

## 10. 构建与部署

### 10.1 脚本（Node + pnpm）

| 命令 | 脚本 | 说明 |
|---|---|---|
| `pnpm start` | `python -m http.server 8000` | 本地预览（需 HTTP 访问，`fetch` 加载 .md） |
| `pnpm run vendor` | `scripts/vendor-assets.mjs` | 从 node_modules 同步 markdown-it / KaTeX → `assets/vendor/` |
| `pnpm run build` | `node scripts/vendor-assets.mjs && node scripts/generate-feed.mjs` | vendor + 重新生成 feed.xml / sitemap.xml |

`generate-feed.mjs`：读取 `posts.js` → 用 markdown-it + KaTeX 渲染摘要与全文 → 输出 RSS 2.0 `feed.xml` 与 `sitemap.xml`（文章页 URL `post.html?id=…`）。

### 10.2 CI/CD（deploy.yml）

推送 `main` 或手动触发 → `pnpm install --frozen-lockfile` → `vendor-assets + generate-feed` → `touch .nojekyll` → `actions/configure-pages` + `upload-pages-artifact` → `actions/deploy-pages`。

> 仓库需在 Settings → Pages 将来源设为 **GitHub Actions**（见 README）。

## 12. 注意事项

1. **勿手改 `assets/vendor/`**：由 `vendor-assets.mjs` 同步，改动会被覆盖。
2. **文章与技术文档依赖 HTTP 加载**：`file://` 直开 `post.html` / `docs.html` 时 `fetch` 受限，会走兜底渲染器；本地预览请用 `pnpm start`。
3. **新增图标**：追加到 `assets/icons.svg` 的 `<symbol id="icon-xxx">`，页面中 `<use href="assets/icons.svg#icon-xxx">` 引用。
4. **CSS 变量优先**：改色/间距尽量走变量，避免硬编码颜色，保证深浅主题与主题色联动一致。
